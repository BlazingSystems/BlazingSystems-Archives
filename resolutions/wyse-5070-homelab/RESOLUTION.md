# Dell Wyse 5070 Homelab / PisoWiFi Server — resolution

**Status:** INFRASTRUCTURE PLAN / NO SINGLE DEPLOYABLE SOFTWARE ARTIFACT

The Dell Wyse 5070 J5005 system was considered as a low-power homelab/PisoWiFi host, including roles such as local router/controller, storage/SFTP services and lightweight browser/admin use.

The recovered work is architecture and troubleshooting guidance rather than a finished software product. Reliability topics included SSD/filesystem integrity, backup of PisoWiFi configuration/database/license data, ventilation and protection from abrupt power loss.

## Resolution

Keep this as an infrastructure plan rather than inventing a “final image.” A future deployment should document the exact base OS, partitions, service versions, firewall rules, storage mount strategy, backup/restore procedure and hardware test results before producing any reusable disk image.
