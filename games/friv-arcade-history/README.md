# Friv / BlazeSystems Arcade History

**Status:** ARCHIVED / SUPERSEDED

Historical browser-arcade work progressed from a local Friv-style launcher toward SNES and multi-emulator experiments before the current public **BlazeSystems Arcade** portfolio edition was created.

## Identified milestones

Historical Library records include builds corresponding to:

- an early corrected single-file Friv-style arcade branch;
- a later SNES-oriented playable branch;
- a multi-emulator direction;
- later BlazeSystems portable/hybrid variants.

## Public archive decision

The raw historical HTML/emulator payloads are **not** published in the current archive. Some versions incorporated or depended on third-party emulator/runtime material and were created around user-supplied game content, so public redistribution rights are not clear enough for a portfolio repository.

The public portfolio instead keeps an original, dependency-free demonstration that shows the launcher/game-design direction without commercial ROMs, BIOS files or unreviewed third-party payloads.

Current public project:

https://github.com/BlazingSystems/BlazingSystems-Projects/tree/main/games/blazesystems-arcade

## Archive policy

Historical filenames and engineering progression may be documented, but redistributable source or payloads are published only when ownership/license status is clear. Raw Library artifacts remain private unless separately reviewed and sanitized.
