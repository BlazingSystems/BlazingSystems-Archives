## Resolution Topics

The archive records earlier work including OpenWrtFi, Huawei HG8145v5 research, ESP8266 TOTP/2FA, Dell Wyse homelab planning, five-face LED-cube work, noise-threshold control, older Pisonet designs, browser runtime history and other projects that do not currently have a publishable final implementation.

## Archive Standard

A useful archive record answers:

1. What was the engineering objective?
2. What implementation direction was explored?
3. Why was it paused, superseded or withheld?
4. What remains valid or reusable?
5. What would a safe restart look like?

If original source is rediscovered, it is reviewed privately first. Public GitHub receives only material that is safe, attributable and honest about its validation state.

## Confidentiality Boundary

Employer/client records, real operational datasets, production credentials, private keys, raw router backups, device-identity dumps and proprietary forms stay outside public GitHub.
